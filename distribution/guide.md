# 단일 EXE 배포

배포할 때는 이 폴더의 **SkeaClock.exe 하나만** 전달하시면 됩니다. 설치 프로그램, source 폴더, 별도 Visual C++ 런타임 설치는 필요하지 않습니다. Windows 10/11 x64용이며, Windows의 GDI+와 Media Foundation을 사용합니다. 미디어 기능이 빠진 Windows N 등의 환경에서는 미디어 팩 경고를 표시하며, 알람 소리 재생을 위해 해당 Windows 미디어 기능을 설치해야 합니다.

## 이 폴더의 구성

- `SkeaClock.exe`: 완성된 배포 파일. 41,917,952바이트, 약 39.98MiB. 볼 변형 개선·원본 놓기 GIF, 예외 하위 메뉴의 비동기 조회와 알람 파일 무음 재생·전체 오디오 검사, 시간 표시 중 시침 95%·분침 105% 길이와 애니메이션 전환 보간 반영.
- `build.cmd`: 배포용 EXE를 다시 만드는 실행 파일.
- `build.ps1`: 원본을 작업 폴더로 복사하고 자료를 포함하여 컴파일하는 절차.
- `standalone.h`: 내장 자료 준비와 사용자 설정 경로 지정에 필요한 시작 처리.
- `guide.md`: 사용·빌드·검증 기록.

## 실행과 저장 위치

첫 실행 시 EXE에 포함된 이미지·음원·좌표 26개를 `%LOCALAPPDATA%\SkeaClock\assets`에 저장합니다. 총 41,471,729바이트, 약 39.55MiB입니다. 다음 실행에서는 내용을 비교해 동일한 파일을 재사용하고, 없거나 바뀐 자료만 복원합니다. 비교는 시작할 때 한 번만 수행하며, 실행 중 추가 타이머나 주기적 검사는 없습니다.

설정은 `%LOCALAPPDATA%\SkeaClock\skea-clock.ini`에 저장됩니다. 따라서 EXE를 옮겨도 같은 Windows 사용자 계정에서는 설정이 유지됩니다. EXE와 자료를 합친 디스크 사용량은 약 79.52MiB이며 설정·파일 시스템 오버헤드는 별도입니다. 사용자 데이터 폴더에 쓰기 권한과 여유 공간이 있어야 합니다.

기존 개발 버전의 `bin\skea-clock.ini`는 자동으로 가져오지 않습니다. 기존 설정을 이어 쓰려면 두 프로그램을 종료한 뒤 그 파일을 위 설정 경로에 복사하십시오. 사용자가 별도로 지정한 알람 음원은 EXE에 포함되지 않으므로 해당 음원 파일은 지정한 위치에 남아 있어야 합니다.

기존 프로그램과 배포용 프로그램은 기존의 단일 실행 제한을 공유합니다. 한쪽이 실행 중이면 다른 쪽은 새 시계를 띄우지 않습니다.

시작할 때와 알람 소리를 선택할 때 무음 재생을 확인한 후 오디오를 끝까지 디코딩하여 검사합니다. WAV·MP3의 기록된 데이터 크기와 실제 파일 크기도 비교합니다. 파일 오류가 확인되면 경고를 표시하고 등록된 사용자 지정 경로를 지운 뒤 기본 알람으로 전환합니다. 원본 음원 파일은 삭제하지 않습니다. 미디어 기능 누락은 경고만 표시하고 선택을 유지합니다. 검사 중에는 파일 길이에 따른 읽기·CPU 비용이 발생합니다. 영상 화면은 디코딩하지 않으며 오디오 데이터를 전체 보관하거나 임시 음원으로 저장하지 않습니다. 정상 무음이나 디코더가 오류 없이 복구한 손상까지 판별하는 것은 아닙니다.

더 이상 사용하지 않을 때는 프로그램을 종료하고 EXE와 `%LOCALAPPDATA%\SkeaClock` 폴더를 삭제하면 됩니다. 이 폴더를 삭제하면 설정도 삭제됩니다. 자료만 다시 만들려면 그 안의 `assets` 폴더만 삭제하십시오.

## 다시 빌드하기

이 `distribution` 폴더를 현재 프로젝트 안에 둔 상태에서 `build.cmd`를 실행하십시오. 빌드에는 상위 폴더의 원본 코드·source 자료와 Visual Studio Build Tools의 C++ 데스크톱 개발 도구 및 Windows SDK가 필요합니다. **완성된 EXE의 실행에는 이 도구들이 필요하지 않습니다.**

빌드 과정은 다음과 같습니다.

1. 원본 코드와 좌표 생성에 필요한 자료를 `distribution\.build`에 복사합니다.
2. 복사본에서 기존 `prepare-assets.ps1`을 실행해 좌표를 생성합니다. 원본 source에는 쓰지 않습니다.
3. 실행에 필요한 자료만 Windows 리소스로 포함합니다. 원본 영상·압축 파일·편집 도구·개발 문서는 포함하지 않습니다.
4. 복사한 C++ 파일의 설정 경로와 자료 경로 초기화만 배포용 시작 처리로 바꿉니다. 시계·알람·효과음·애니메이션 및 100ms 타이머 코드는 그대로 사용합니다.
5. `/O2 /MT /W4 /WX`로 빌드하고 성공한 EXE를 이 폴더에 놓습니다. 성공 후 임시 `.build` 폴더는 삭제합니다.

원본 구조가 달라져 경로 초기화 부분을 찾지 못하면 빌드를 중단합니다. 이 경우 `build.ps1`의 복사본 변환 부분을 원본에 맞춰 수정해야 합니다. 실행 중인 배포 EXE는 종료한 뒤 다시 빌드하십시오. 빌드가 실패하면 기존 배포 EXE가 남을 수 있으므로 성공 메시지를 확인하십시오.
