# Skea clock

스키아의 바보털은 세계제일


스키아를 시계로 사용해봅시다.

윈도우 화면에 스키아 시계를 상시 띄위둘 수 있습니다.

꿀밤 및 볼당기기 상호작용이 가능하며, 알람을 맞춰둘 수 있습니다.
