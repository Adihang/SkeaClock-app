# Skea clock

> **スキアのアホ毛は世界一**

<img src="docs/images/clock-0410.png" alt="4時10分を示すスキアの時計" width="320">

スキアを時計として使ってみましょう。  
Windowsの画面にスキアの時計を表示して、デコピンや頬を引っ張る操作を楽しんだり、アラームを設定したりできます。

## ダウンロードと起動

インストールは不要です。

**[最新版をダウンロード (.exe)](https://github.com/junhwan123/SkeaClock/releases/latest/download/SkeaClock.exe)**

上記のリンクを使用するか、Releasesページから最新版をダウンロードしてください。

## 使い方

時計を**右クリック**すると、設定メニューが開きます。

<img src="docs/images/menu-settings.png" alt="時計の右クリック設定メニュー" width="240">

### 時計の見た目

**背景表示(배경 표시)**、**目盛り表示(눈금 표시)**、**数字表示(숫자 표시)**をそれぞれオン・オフに切り替えて、お好みの見た目に設定できます。

| すべてオフ | 背景・目盛りをオン | 背景・目盛り・数字をオン |
| ------- | ------------- | ------------------- |
| ![すべてオフ](docs/images/clock-1010-none.png) | ![背景・目盛りをオン](docs/images/clock-1010-background-ticks.png) | ![背景・目盛り・数字をオン](docs/images/clock-1010-all.png) |

### アラーム

スキアが指定した時刻と曜日にアラームを鳴らしてくれます。右クリックメニューの**アラームを追加(알람 추가)**から時刻と曜日を設定できます。

<img src="docs/images/alarm-editor.png" alt="アラームの時刻と曜日を設定するウィンドウ" width="360">

登録したアラームは設定メニューの**アラームを追加(알람 추가)**の下に表示されます。各アラームのサブメニューから**アラームを編集(알람 편집)**または**アラームを削除(알람 삭제)**を選択できます。

<img src="docs/images/menu-alarm.png" alt="登録済みアラームの編集・削除メニュー" width="240">

### サウンド設定

スキアの効果音とアラーム音は、それぞれ個別に設定できます。  
効果音は音量のみ調整できます。初期値は**80%**です。

<img src="docs/images/menu-effects.png" alt="効果音の音量を選択するメニュー" width="160">

アラーム音は音量だけでなく、音声ファイルも個別に設定できます。  
選択したファイルは**1つだけ**保存され、**デフォルトアラーム(기본 알람)**と選択したアラームのどちらかを選べます。  
**ファイルが削除されたり移動されたりすると、選択が解除される**ため、ご注意ください。

<img src="docs/images/menu-alarm-sound.png" alt="アラームファイルの選択(알람 파일 선택)とデフォルトアラーム(기본 알람)の設定メニュー" width="240">

### 常に手前に表示(항상 위에 표시)の設定

スキアの時計がほかのウィンドウよりも手前に表示され続けるように設定できます。  
**常に手前に表示(항상 위에 표시)**をオンにすると、ほかのプログラムを使用している間も時計を確認できます。チェックを外すと、ほかのウィンドウの背後に隠れる場合があります。

<img src="docs/images/menu-exceptions.png" alt="最前面固定の例外(최상단 고정 예외)にするプログラムを選択するメニュー" width="240">

特定のプログラムを使用するとき、時計が手前に重ならないように例外を設定できます。  
**最前面固定の例外(최상단 고정 예외)**でプログラムを選択すると、そのプログラムの使用中は時計がそのプログラムの背後に表示されます。もう一度選択すると例外が解除されます。  
一覧に目的のプログラムがない場合は、**プログラムを選択...(프로그램 선택...)**をクリックして、実行ファイルを直接追加できます。

### その他の項目

**タスクバーに表示(작업 표시줄 표시)**をオンにすると、スキアの時計がタスクバーにも表示されます。チェックを外すと、タスクバーから非表示にできます。  
**サイズ・位置の調整(크기·위치 이동)**で、時計のサイズと位置を自由に調整できます。  
**表示ディスプレイ(표시 디스플레이)**から、時計を表示する画面を選択できます。サイズと位置のデータは画面ごとに個別に保存されます。

<img src="docs/images/menu-displays.png" alt="時計を表示するディスプレイを選択するメニュー" width="320">

## 補足事項

このプログラムはAIを活用して制作しました。  
可能な限り最適化に配慮して制作していますが、不具合が発生する可能性があります。

設定やプログラムのデータは、`%APPDATA%`フォルダー内の \Local\SkeaClock フォルダーに保存されます。  
関連データを残さず完全に削除したい場合は、.exeファイルだけでなく、そのフォルダーも削除してください。
